# Security and responsible reporting

PRISM is a research prototype. The public service accepts user-supplied point-cloud files and applies file and frame limits, but is not a safety-critical perception service. Do not upload private scans or personal data to the public demo.

If you find a security issue, contact the repository owner privately through GitHub rather than publishing exploit details or sensitive logs in an issue. Include the affected route or file format, a minimal reproduction and the impact. Do not include credentials or private scan data.

The project does not make a production safety, tracking or vehicle-readiness claim.
